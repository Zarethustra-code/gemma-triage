# Screenshots

Drop submission screenshots here and they will render in the main
[README](../README.md#screenshots).

Expected filenames:

| File | What to capture |
|---|---|
| `screenshot-dashboard.png` | The dashboard just after a run — engine status bar, stat tiles, the sorted result list with coloured category badges |
| `screenshot-detail.png` | One email expanded — Gemma's reasoning, the editable suggested reply, the **📧 Create Gmail Draft** button, and the task / calendar-event cards with their **Prepared payload** status |
| `screenshot-trace.png` | The **🧠 Raw agent trace** accordion open, showing the JSON Gemma actually produced and the tool calls it produced |

To capture them:

```bash
python app.py          # → http://localhost:7860
```

Press **⚡ Run Triage**, then screenshot each view.
